# Ethernet Hardware and Testing

## Ethernet GPIO Mapping
| Pin | Function |
|---|---|
| 10 | Ethernet TX Enable |
| 11 | Ethernet TXD0 |
| 12 | Ethernet TXD1 |
| 13 | Ethernet CSDV |
| 14 | Ethernet RXD0 |
| 15 | Ethernet RXD1 |
| 16 | LAN8720 MDIO  |
| 17 | LAN8720 MDC   |
| 18 | LAN8720 Reset |
